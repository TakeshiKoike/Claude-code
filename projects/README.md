# projects（ハーネスで進める企画）

使い方の決まりはリポジトリ直下の `CLAUDE.md` にあります。

## 新しい企画の始め方
1. `_ひな形/` をコピーして、`projects/<企画名>/` を作る
2. `企画書.md` に先生の言葉を書く
3. 司令塔（メインの会話）に「この企画を進めて」と伝える

## クラウドでもパソコンでも使える
係（`.claude/agents/harness-*.md`）と決まり（`CLAUDE.md`）はリポジトリに入っています。
- クラウド：このリポジトリでセッションを始めれば、そのまま使えます
- パソコン：`git clone` したフォルダで `claude` を起動すれば、同じ係が使えます
  （パソコンの `~/.claude/agents/` にある他のハーネスの係とは名前が別なので、ぶつかりません）
