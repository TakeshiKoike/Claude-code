# スタートアッププロジェクト ナレッジベース

教材の開発、SNS を軸にしたマネタイズ、サービス・コンサルティング・マネジメントを総合的に提供する事業を立ち上げるための計画とノウハウをここにまとめます。
**個人事業主 → 法人化 → スタートアップ（3人のパートナーシップスタジオへ移行）** の順に段階を踏んで進めます。

> このフォルダは「生きた事業計画書」です。決めたこと・試したこと・学んだことを随時書き足していきます。

## 基本方針（3つ）

1. **小さく始めて、売れてから大きくする**：まず1つの商品を10人に売ってから、2つ目の商品を作る。
2. **「教える → 仕組みにする → 任せる」の順で育てる**：コンサル（労働集約）で顧客の課題を学び、教材（資産型）に変え、最後はチームやサービスに任せる。
3. **数字で判断する**：毎週、同じ指標を記録する（[`02_business/kpi.md`](02_business/kpi.md)）。
