# 未決事項（まずここを埋める）

計画の精度は、ここの答えで大きく変わります。分かるところから書き込んでください。

## 誰に・何を
- [ ] **ターゲット顧客は誰か？**（例：看護師個人／看護管理者／病院・施設／看護学生／他業種の個人事業主）
- [ ] **その人の一番の悩みは何か？** お金を払ってでも解決したいことは何か？
- [ ] **自分の強み・実績は何か？**（資格、現場経験の年数、指導実績、フォロワー数など）
- [ ] 教材のテーマ候補を3つ挙げると？

## 体制
- [ ] パートナースタジオの3人の役割分担は？（例：コンテンツ／営業・マーケ／技術・運営）
- [ ] パートナースタジオの完成・移行時期の目安は？
- [ ] 本業（勤務）を続けながら進めるか？ 副業規定は確認済みか？

## お金
- [ ] 最初に使える資金はいくらか？
- [ ] 「生活できる」と判断する月の売上ラインは？
- [ ] 外部から資金を調達する（VC・融資・補助金）つもりはあるか？

## 時間
- [ ] 1週間で事業に使える時間は？
- [ ] 1年後・3年後にどうなっていたいか？
