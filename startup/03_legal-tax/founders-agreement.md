# 共同創業（3人のパートナーシップ）で決めておくこと

共同創業のトラブルで多いのは「お金」「役割」「誰かが抜けるとき」の3つです。**仲が良いうちに、文書で決めておく**のが一番の予防です。

## 創業者間契約で決める項目
- [ ] **役割と責任**：誰が何の最終決定権を持つか（CEO／CTO／COO など）
- [ ] **持株比率**：均等（33%ずつ）は意思決定が止まりやすい。代表者が過半数を持つ形が一般的
- [ ] **ベスティング**：株式を4年ほどかけて段階的に確定させる。途中で抜けた人の株式をどうするか（買い戻しの価格・条件）
- [ ] **時間と報酬**：各自が使う時間、役員報酬をいつから出すか
- [ ] **知的財産**：教材・コード・ブランドの権利は会社に帰属させる（個人の持ち込み分の扱いも決める）
- [ ] **競業避止**：在籍中・退任後に同じような事業をしてよいか
- [ ] **意思決定のルール**：全員一致が必要な事項と、多数決でよい事項
- [ ] **解散・売却のとき**の分け方

## 進め方
1. このリストを3人で話し合い、合意事項をメモにする
2. スタジオの法人化に合わせて、弁護士に契約書と定款にしてもらう
3. 年に1回見直す
