# 個人事業主としての開業チェックリスト

> 制度は毎年変わります。金額・期限は国税庁のサイトや税理士で必ず最新の情報を確認してください。

## 開業時に出す書類
- [ ] **開業届**（個人事業の開業・廃業等届出書）：開業から1か月以内に税務署へ。e-Tax やオンラインの開業サービスでも出せる
- [ ] **青色申告承認申請書**：開業から2か月以内（1月1〜15日に開業した場合は3月15日まで）。最大65万円の控除を受けるために必須
- [ ] 屋号を決める（屋号付きの銀行口座を作れる）
- [ ] 必要に応じて：都道府県への事業開始等申告書

## お金の管理
- [ ] 事業用の銀行口座とクレジットカードを分ける
- [ ] 会計ソフトを入れる（freee、マネーフォワード、弥生など）
- [ ] **青色申告65万円控除**の条件：複式簿記＋e-Tax で申告（または電子帳簿保存）
- [ ] 領収書・請求書は電子帳簿保存法に合わせて電子で保存する

## インボイス制度（適格請求書）
- 法人の顧客（研修・コンサル）が多いなら、登録を求められることが多い
- 個人向けの教材販売が中心なら、登録しない（免税事業者のまま）という選択もある
- 登録すると消費税の申告・納付が必要になる。軽減措置（2割特例など）の期限と今後の扱いは税理士に確認する

## 副業で始める場合
- [ ] 勤務先の就業規則で副業が認められているか確認する
- [ ] 住民税の徴収方法を「普通徴収（自分で納付）」にすると、副業分が勤務先に通知されにくい（自治体による）
- [ ] 副業の所得が年20万円を超えたら確定申告が必要（住民税は金額に関係なく申告が必要）

## ネットで商品を売るときに必要な表示
- [ ] **特定商取引法に基づく表記**（販売者名・住所・連絡先・価格・返品条件など）。自宅住所を出したくない場合はバーチャルオフィスなどを検討
- [ ] 利用規約・プライバシーポリシー
- [ ] SNS で PR をするときは **ステマ規制**（景品表示法）に従い「広告」「PR」と明記する
- [ ] 医療・健康の分野を扱う場合は、**医療広告ガイドライン・薬機法**に触れる表現（効果の断定など）に注意する
