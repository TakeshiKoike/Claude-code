# パートナースタジオへの移行計画

個人事業で育てた資産を、3人のスタジオ（法人）へスムーズに移すための準備です。**今のうちから「後で移せる形」で作っておく**のがコツです。

## 今からやっておくこと
- [ ] 事業用のメールアドレス・アカウントは、個人のものと分けて作る
- [ ] ドメインを取得し、メールやサイトはそのドメインで運用する
- [ ] 教材・資料は共有フォルダ（Google Drive / Notion）にまとめる
- [ ] 業務の手順を書き残す（このリポジトリの `05_operations/` に追加していく）
- [ ] パスワードはパスワード管理ツールで管理し、共有できるようにする

## 移す資産の一覧（棚卸し）

| 資産 | 現在の持ち主 | 移行方法 | 状況 |
|---|---|---|---|
| 教材の著作権 | 個人 | 譲渡契約 or 利用許諾 | 未着手 |
| SNSアカウント | 個人 | 運用権限を共有／ビジネスアカウント化 | 未着手 |
| メルマガ・LINEのリスト | 個人 | 規約とプライバシーポリシーを確認して移管 | 未着手 |
| ドメイン・サイト | 個人 | 名義変更 | 未着手 |
| 顧客との契約 | 個人 | 新しい契約を結び直す | 未着手 |
| 看護デジタルニュース | 個人 | リポジトリとサーバーを移す | 未着手 |

## 注意点
- 個人から法人へ資産を譲るときは、価格の付け方で税金が変わることがある → 税理士に相談
- 顧客の個人情報を移すときは、プライバシーポリシーで第三者提供・事業承継をどう書いているかを確認する
