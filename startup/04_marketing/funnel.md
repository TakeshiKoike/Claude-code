# 集客の流れ（ファネル）と SNS 戦略

## 全体の流れ

```
[知ってもらう]   SNS（X / Instagram / YouTube / TikTok / note）・看護デジタルニュース
      ↓
[つながる]       メルマガ・LINE公式に登録（無料特典：チェックリストやミニ講座）
      ↓
[信頼する]       配信で役立つ情報を届ける・無料セミナー
      ↓
[買う]           講座・個別相談・研修
      ↓
[続ける・紹介]   コミュニティ・上位の商品・口コミ
```

**SNS のフォロワーは借り物、リスト（メルマガ・LINE）は自分の資産。** アカウント凍結や仕様変更に備え、SNS から自分のリストへ移ってもらうことを常に意識します。

## SNS の選び方
最初は **1つのメインと1つのサブ** に絞ります。

| SNS | 向いている内容 |
|---|---|
| X | 専門知識・考え方の発信、同業者とのつながり |
| Instagram | 図解・カルーセル、女性が多い層 |
| YouTube | 教材と相性がよい。検索から長く見られる |
| TikTok / ショート | 短期間で認知を広げる |
| note | 長文の発信と有料記事の販売を兼ねられる |

## 発信の型（毎週回す）
- **教える投稿**（ノウハウ・図解）：全体の6割
- **共感の投稿**（自分の経験・失敗談・現場のリアル）：3割
- **案内の投稿**（商品・セミナーの告知）：1割

## 看護デジタルニュースの活用案
- 記事の最後にメルマガ・LINE登録の案内を置く
- 人気の記事テーマを、SNS投稿・教材の題材にする
- 看護管理者・病院向けの研修やコンサルの問い合わせ窓口にする
